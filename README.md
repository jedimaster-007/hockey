# Tir de précision

Jeu de hockey au doigt, dans le navigateur : glisse le doigt de la rondelle vers le filet. La direction vise, la vitesse du geste donne la hauteur.

**Jouer :** https://jedimaster-007.github.io/hockey/

Épreuves : Cibles, Chrono, Barre, Bouteilles, Tour du monde, Gardien (Félix Gagnon, #35), et le Super défi qui les enchaîne toutes pour un grand total.

Un seul fichier, `index.html`, sans installation. Conçu pour iPhone en mode portrait ; fonctionne aussi à la souris.

## English

Finger-swipe hockey in the browser: swipe from the puck toward the net. The direction aims, the swipe speed sets the height. Six events (Targets, Time Attack, Crossbar, Bottles, Around the World, Goalie) plus the Super Challenge. The game switches between French and English with the FR/EN button on the home screen.
